# CLI 模块 · 命令行接口

> P2 | src/cli/ 模块文档

## 模块职责

**CLI 模块** 实现命令行接口核心逻辑，包括命令解析、输入/输出处理、传输层、更新检查等。是用户与 Claude Code 交互的主要入口。

## 关键功能

### 输出系统 (`print.ts`)
- ANSI 彩色输出
- 结构化输出（JSON/NDJSON）
- 进度条和加载动画
- 表格和列表格式化
- 错误消息渲染

### 传输层 (`transports/`)
- 标准输入/输出
- STDIO 传输
- 网络传输（远程模式）
- 管道传输

### 命令处理 (`handlers/`)
- 参数解析
- 命令路由
- 错误处理
- 帮助生成

### 更新系统 (`update.ts`)
- 版本检查
- 自动更新
- 更新通知

---

## 架构模式

1. **传输抽象** — 统一接口支持多种传输方式
2. **结构化输出** — 支持机器可读的 NDJSON 格式
3. **优雅退出** — 统一处理退出码和清理逻辑
4. **增量更新** — 支持后台检查和热更新
